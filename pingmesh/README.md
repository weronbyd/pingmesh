# Pingmesh

Pingmesh is a tool for monitoring network latency between multiple hosts.

## Overview

Pingmesh consists of three main components:

- **Agent**: Runs on each monitored host and performs ping measurements.
- **Controller**: Manages agents and collects measurement data.
- **Aggregator**: Aggregates and stores measurement data from multiple controllers.
